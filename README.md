# ANN – الشبكة الجزائرية للأخبار

تطبيق أندرويد (Flutter) لصناعة أخبار الشبكة الجزائرية للأخبار بالذكاء الاصطناعي (Gemini API) وتصميم صورها للنشر على منصات التواصل، بالهوية البصرية للشبكة.

الموقع الرسمي: [anndz.dz](https://anndz.dz/)

## الهوية البصرية
- **الألوان:** الأحمر الأساسي `#B61A1B` وأحمر الشعار `#E50000` والبرتقالي `#F67C01` والأبيض (مأخوذة من الملصقات المعتمدة).
- **الخط:** beIN Normal (`assets/fonts/BeIN-Normal.ttf`).
- **الشعار:** `assets/images/ann-logo-red.png` و`ann-logo-white.png` (الأبيض للخلفيات الحمراء).
- **الملصقات المرجعية:** الصور المعتمدة في مجلد المشروع الأصلي (آخر خبر، هام، عاجل، أحوال الطقس).

## الميزات

### الصياغة
- **نوع المدخلات إلزامي:** تصريح، عاجل، آخر خبر، هام، ريل، يوتيوب.
- **المدخلات:** نص، روابط (استخلاص على الجهاز، ثم Gemini URL Context عند الفشل)، يوتيوب، صور ولقطات شاشة متعددة، كاميرا، ملفات صوت وفيديو (حتى ~10 دقائق). يمكن الجمع بينها في خبر واحد.
- **المخرجات (JSON Schema ثابت):** نقاط الخبر، العنوان الرئيسي (3 جادة و3 تفاعلية)، كابشن السوشيال ميديا، عنوان الصورة المصغرة، والمصدر.
- **التصريحات:** جملة تقديم (صفة المتحدث + #اسمه + الموضوع) ثم التصريحات مُعاد صياغتها على لسان المتحدث، كل تصريح يبدأ بـ 🔴.
- **الفرنسية:** زر يولّد المخرجات بالفرنسية انطلاقاً من النسخة العربية بعد تعديلها.
- **تنبيهات دون منع:** تجاوز حدود الكلمات، غياب المصدر أو المتحدث، وملاحظات النموذج.
- **السجل:** يُحفظ كل خبر محلياً مع إمكانية البحث وإعادة الفتح.
- **المشاركة إلى التطبيق:** من المتصفح أو فيسبوك أو يوتيوب أو المعرض (مشاركة ← ANN).
- **التحقق من الدقة:** لكل نقطة اقتباس حرفي من المصدر، ويتحقق التطبيق على الجهاز من وجوده ومن الأرقام، وتظهر الحالات: ✔ موثّقة، ⚠ تحتاج مراجعة، ؟ غير قابلة للتحقق.

### التصميم
- قوالب بمقاسات 2000×2000 و1920×1080 و1080×1920، والمرتبطة بنوع الخبر في المقدمة.
- اختيار ما يُكتب على الصورة (العنوان أو الكابشن أو عنوان الصورة المصغرة)، وتحريك الصورة وتكبيرها، وضبط الخط والألوان والإطار والمحاذاة.
- التصدير بالمقاس الأصلي ثم الحفظ في ألبوم «ANN» أو المشاركة.

## القوالب
| نوع المدخلات | القوالب | المقاس |
|---|---|---|
| آخر خبر | بلون كامل، بصورة | 2000×2000 |
| عاجل | بلون كامل (أحمر الشعار)، بصورة | 2000×2000 |
| هام | بلون كامل، بصورة | 2000×2000 |
| تصريح | اقتباس (الصورة يساراً + التصريح + اسم المتحدث وصفته) | 2000×2000 |
| ريل | العنوان على مربعين (أبيض ثم أحمر) | 1080×1920 |
| يوتيوب | العنوان على مربعين (أبيض ثم أحمر) | 1920×1080 |

لتوليد الخلفيات من جديد (يتطلب ImageMagick):
```bash
MAGICK=magick bash tool/generate_templates.sh
```

## البنية
```
lib/
  core/            قواعد النصوص، التحقق من الدقة، والثيم (ألوان ANN)
  models/          نماذج البيانات (الخبر، المدخلات، القوالب)
  services/
    ai/            طبقة الذكاء الاصطناعي المعزولة (Gemini)
    url_extractor.dart, history_repository.dart, ...
  ui/              الشاشات: الصياغة، النتائج، التصميم، السجل، الإعدادات
assets/
  templates/       القوالب المضمّنة + templates.json
  fonts/           خط beIN
  images/          شعار ANN
tool/              توليد خلفيات القوالب
```

## التطوير
```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```
