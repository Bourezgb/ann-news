# ANN Studio (نسخة الويب المحلية)

أداة تحرير للصحفي المتربص في الشبكة الجزائرية للأخبار، تعمل على جهازك:
جلب الخبر من رابط، ثم الكتابة، ثم التدقيق اللغوي، ثم السيو، ثم تصميم صورة السوشيال.

## التشغيل
المتطلب: Node.js 20 أو أحدث، ولا توجد حزم خارجية.

```bash
cd web
npm start
```

ثم افتح http://127.0.0.1:3000 في المتصفح.

## الاختبارات
```bash
npm test
```

## ما هو موجود الآن (الإصدار 0.1)
- **المقالات:** إنشاء وتحرير وحذف، وتخزينها في `data/articles.json` على جهازك.
- **جلب من مصدر:** لصق رابط خبر، واستخلاص العنوان والوصف والصورة والنص.
- **التدقيق اللغوي:** مسافات، علامات ترقيم، كلمات مكررة، وأخطاء إملائية شائعة مع اقتراح الإصلاح بنقرة.
- **السيو:** درجة من 100، وطول العنوان والوصف، ووجود الكلمة المفتاحية في العنوان والوصف وأول 100 كلمة، وكثافتها، والرابط المقترح (slug).
- **تصميم السوشيال:** قوالب ANN بالمقاس الأصلي (2000×2000 و1080×1920 و1920×1080)، مع خط beIN، وتصدير PNG.

## ما ليس موجوداً بعد
- الصياغة بالذكاء الاصطناعي والتحقق من الاقتباسات (كانت في تطبيق Flutter).
- التدقيق النحوي الكامل (الحالي قواعد وقائمة أخطاء شائعة فقط).
- الفيديو والإنفوغراف والتصريحات بالصوت والصورة.
- الصيغ النهائية للتصدير والنشر، وسنناقشها بعد اكتمال النسخة المحلية.

## البنية
```
web/
  src/server.js     خادم HTTP بلا مكتبات، وواجهة JSON
  src/store.js      تخزين المقالات في ملف JSON
  src/extract.js    استخلاص محتوى الصفحة من الرابط
  public/js/app.js     الشاشات والتوجيه
  public/js/design.js  مصمم السوشيال (Canvas)
  public/js/checks.js  منطق السيو والتدقيق (مشترك، مُختبر)
  public/assets/       الخط والشعار والقوالب المأخوذة من مشروع Flutter
  test/                اختبارات node:test
```
